# 预置行政区边界

数据来自 [zhChuXiao/ChinaGeoJson](https://github.com/zhChuXiao/ChinaGeoJson)，固定版本 `7aa2c5fabc6a892015625898c3482874b233f9de`，上游来源为阿里云 DataV.GeoAtlas。MIT 授权全文见同目录 LICENSE。

`china.json` 收录全国和 34 个省级区域。全国取自上游根目录 china.json，各省取自 province 目录。将 Polygon / MultiPolygon 的外环转换为应用已有的多面格式，保留离岛；市级外环按并集参与下载，内部行政边界不会重复下载瓦片。与现有区域导入格式一致，暂不表达外环内部的孔洞。

当前预置边界已确认无需纠偏，行政区选区始终保留源数据坐标，不进行坐标转换。边界用于下载选区，不作为测绘级行政界线数据。

`cities.json` 是同一版本省级文件中的 363 个市级区域索引（含自治州、盟及源数据标记为市级的省直辖区域）。每项保存行政代码、上游中文名称及外环在对应省份数组中的起始位置和数量，复用已有坐标，不增加重复边界。直辖市和港澳下级为区县，台湾源文件只提供省级边界，这些区域不提供城市选项，仍可选择完整省级范围。

下载面板使用“国家 → 省份 / 直辖市 → 城市 / 自治州”联动下拉框；当前国家数据仅中国。省份选择“全国”应用国家范围，城市选择“全部范围”应用所选省份，更换省份清空已选城市。保持“追加到当前范围”勾选，可多次选择不同省市组合下载；取消勾选则替换当前选区。城市名称使用上游官方中文名。

数据在打开下载面板时按需加载，无需联网。更新时应固定新的上游版本，重新核对 35 个区域、外环有效性及许可，并执行区域单元测试。城市索引必须与 `china.json` 同步更新，在 ChinaGeoJson 固定版本的本地目录上运行：

```bash
python3 scripts/build-city-index.py /path/to/ChinaGeoJson
```

脚本会逐点校验全部省级外环与 `china.json` 一致，校验通过后才生成城市索引；若上游边界变化，需先同步更新省级边界，禁止套用其他版本索引。
